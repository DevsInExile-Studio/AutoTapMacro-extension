A FEW NOTES FROM THE WORKSHOP

Less repeating. More doing.

A small collection of tools for the things you do again and again.

01

Make your first recording

Open a website, click the AutoTap extension icon, then Record this tab. Use any standard mouse button, turn the wheel, type, choose options and scroll as usual. Use the floating panel to pause or stop. Your macro saves as you go.

02

Fine-tune the little things

Select a macro to rename it, edit selectors and values, change timing, reorder actions or add a wait. Set cycles and speed, save, then play it on its original website.

03

A place for your JavaScript

Create or import a .user.js file in the JavaScript tab. Enable Allow user scripts in Chrome’s extension details. Run once on a connected tab, or specify site patterns and enable automatic execution.

04

Keep your collection close

Everything is stored in this browser profile. Export a JSON backup, including GM values, to move your collection. Imported scripts always start with automatic execution off. Android tap macros use a different format.

Browser boundaries. Recording and playback work in the top-level page. Navigation or reloading stops the session and keeps recorded actions. Embedded frames, closed shadow roots, protected browser pages and sites requiring trusted hardware input are not supported. Password, payment, one-time-code and file fields are skipped. Other typed values are saved in your macros.

Script compatibility. A supported GM subset provides per-script storage, styles, elements, info, logs, menu commands and opening tabs. Declare the required grants in the isolated context. Toolbox includes recipes, auto-run pause and blocked sites; Activity shows local results. Network requests, resource files, value-change listeners, notifications, downloads and plain-text clipboard writes are supported with declared grants. Declared libraries/resources can be fetched into a reviewable draft; they never update automatically. Cookie APIs, unsafeWindow, regex URL rules and streaming network responses remain unsupported. A running script cannot be cancelled by the macro Stop button; reload its page to clear timers or listeners. Only run code you trust.
