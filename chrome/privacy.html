Your routines stay yours.

No account, analytics SDK, advertising SDK, telemetry endpoint or extension-operated server. Your automation collection is not sold or sent to the developer.

Local collection and previews

Local storage contains macros, website URLs/selectors/labels, ordinary typed values, selections, keys, mouse buttons/click counts, pointer paths/positions/timing/button states, wheel gestures/scroll targets, scroll positions, timing, preferences, favorites/tags, JavaScript, metadata/grants, attached libraries/resources, GM values, auto-run controls and the last 100 activity entries. GM_log can contain data your script chooses to log. Session storage holds active sessions, capabilities, commands/listeners and native-feature callback information. Capabilities are not exported.

Recognized private inputs are excluded, but ordinary fields and visible text can contain personal information. Pause recording before entering anything you do not want saved. Page extraction is explicit; its preview is not automatically stored in the library. JSON backups include code, values and attachments. Completed downloads and exports remain on your device until deleted.

Network and attached code

User scripts can read/change page content and make network requests. GM requests and network downloads require @connect plus Chrome site access. They omit credentials by default; anonymous:false requests credentials under Chrome's rules. Request data goes to the endpoints your code selects.

Fetch declared files for review downloads selected HTTP(S) @require/@resource references only after source permission is granted. These fetches omit credentials, reject redirects, check bounds and supported integrity hashes, and return an unsaved draft. Fetching does not register or run code. There are no silent dependency downloads or automatic updates during auto-run. Review scripts and dependencies before execution.

Permissions and native features

activeTab/scripting inject packaged page tools; storage keeps local data; userScripts executes your code after Chrome's switch is enabled. offscreen supplies the packaged clipboard helper. Optional site access covers selected rule, network and dependency hosts; all-host access requires an explicit broad rule and Chrome approval.

Optional notifications, downloads and clipboardWrite are requested for matching script grants. They allow local notifications, file saving and replacing plain-text clipboard content. Clipboard reading is not requested. Scripts can run in matching authorized frames when enabled. Manual Run targets the top document. GM_openInTab can close only tabs it created.

Your controls

Delete items, edit values, clear Activity, disable scripts, pause future auto-run, block sites or revoke Chrome permissions. Closing a tab cleans its subscriptions and pending GM requests. Reload to clear existing script timers/listeners. Uninstalling removes extension data, while downloaded/exported files remain until you delete them.

The optional Google Play link opens the separate Android listing under Google's policies. The collections do not sync.
